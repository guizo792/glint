    Everything in one box

    One shortcut, one text box, no menus to remember.

    🔎 Finds everything

    Apps, files, folders, settings pages and open windows, across every fixed drive. New files show up within a couple of seconds.

    ⚡ Fast on big disks

    Searches an index held in memory, so results appear as you type, even with hundreds of thousands of files.

    🧠 Learns what you pick

    What you open for a query comes first next time, for every prefix you type. Pin favourites, hide the noise.

    🎯 Filters that read like words

    report ext:pdf in:Finance, plus file:, dir: and app:. Every word must match the name or a folder on its path.

    🧮 Calculator and units

    18% of 240, 2024/3, 10 km to mi, 100 f to c. Enter copies the answer.

    ⚙️ System commands

    Type > for lock, sleep, restart and every Windows settings page, without digging through menus.

    🌐 Web when you want it

    ? rust opens a search; g, ddg, yt and gh are built in. Add your own bangs and links.

    🧩 Extensions

    Small programs in any language that answer to a trigger word. They stay off until you turn them on, and declare what they may do.

    🔒 Private by design

    No network connections of its own and no telemetry. Clipboard history is off by default and skips what password managers mark private.

    Get Glint

    Windows 10 and 11, 64-bit. Free, with no account and no sign-up.

    1. Download the installer from the latest release.
    2. Run it. It installs for your user only and needs no administrator rights.
    3. Press Alt+Space and start typing.

    About the Windows warning

    Glint is a free community project, and code-signing certificates cost money, so the installer is not signed yet. Windows SmartScreen may show “Windows protected your PC”. That means the file is new and unrecognised, not that it was found to be harmful. Choose More info, then Run anyway.

    To check that your download is the file that was published, compare its checksum with the one in the release notes:

    certutil -hashfile Glint_0.1.0_x64-setup.exe SHA256

    Prefer to build it yourself? Everything you run is then built from code you can read. See Building in the README.

    Questions

    Does Glint send anything over the network?

    No. It makes no network connections of its own. Web results only open your browser when you choose them. Usage history is a local file you can clear in Settings. Extensions are the exception to this: they are programs running with your user rights, so only turn on ones you trust.

    Does it search inside files?

    Glint searches names, not contents. The last row of most searches hands the query to Windows’ own search, which can look inside files in the places Windows has indexed.

    How much memory does it use?

    About 100 MB in everyday use on a Windows 11 PC, measured after a search. It draws its window in software inside a single process to avoid the extra GPU process a web view normally starts.

    Is it a beta?

    It is an early release, version 0.1. It is tested and usable every day, but the settings file and extension interface may still change before 1.0. Bug reports and ideas are very welcome.

    What license is it under?

    MIT or Apache-2.0, at your option.
